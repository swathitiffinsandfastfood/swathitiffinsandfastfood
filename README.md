Upgrade my existing website, **Swathi Tiffins & Fast Food**, into a professional, modern, and realistic restaurant website. The design should look like it was created by an experienced human web designer for a real local restaurant, not generated by AI.

* Create a warm, welcoming restaurant atmosphere.
* Use a combination of cream, dark brown, and deep red or orange.
* Use clean typography, natural spacing, and a clear visual hierarchy.
* Avoid excessive gradients, glowing effects, unnecessary animations, glassmorphism, and generic AI-style layouts.
* Make the website look authentic, simple, attractive, and trustworthy.
* Use high-quality food photography that makes the dishes look delicious and realistic.

* Increase or decrease quantities.
* Remove items.

Make the website fully responsive for:

* Android phones
* iPhones
* Tablets
* Laptops
* Desktop computers

On mobile, use a clean navigation menu, appropriately sized buttons, readable text, and food cards that fit the screen without horizontal scrolling.

### 6. Realistic Food Photography

Use genuine-looking photographs of Indian food.

* Avoid obviously artificial-looking AI food images.

* Do not stretch or distort images.
